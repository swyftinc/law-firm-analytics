# Firm profile

A short note the skills read at the start of each run so they never ask the same questions twice. Keep it free of client names, matter details and numbers.

```
firm: [name, or "my firm"]
role: [owner | ops lead | lawyer]
records: [Clio | MyCase | Filevine | spreadsheets | other]
other data: [marketing spend sheet | intake call log | none]
billing: [hourly | flat fee | contingency | mixed]
decision: [Monday partner meeting | where to spend ad dollars | collections | other]
focus: [the two or three metrics that matter most, and why]
targets: [any targets the firm uses, e.g. "realization 85%"]
accent color: [hex, or default]
names in memos: [ok | leave out]
more like this: [what they liked]
less like this: [what they did not]
```

Run date and file names do not belong here.
